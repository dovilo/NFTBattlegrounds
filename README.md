# NFTBattlegrounds

![MiMo](https://img.shields.io/badge/Powered%20by-MiMo%20v2.5--pro-8b5cf6?style=flat-square)

**AI Agent NFT Card Battle Game**

Collectible NFT cards of AI agents. Build decks, battle in turn-based combat. Cards evolve based on wins.

## Features

- **Card Collection** — Core gameplay by autonomous AI agents
- **Deck Builder** — MiMo v2.5-pro reasoning
- **Turn-Based Combat** — Earn rewards through strategy
- **On-Chain** — Fully transparent
- **Multi-Chain** — ETH, Base, Arb, Polygon

## Quick Start

```bash
git clone https://github.com/dovilo/NFTBattlegrounds.git
cd NFTBattlegrounds
open index.html
```
